# Kome.Epochs known-answer vectors. tests/test_epochs.adb reads them.
# DESIGN.md §6 epoch chain (AUDIT.md G5): k_e = f (k_{e+1}, "kome/prev"),
# where f (key, msg) is keyed BLAKE2b-256 (RFC 7693 §2.10, the key is
# k_{e+1}, the message is the 9-byte ASCII label). Derive (k, from, to)
# applies that step (from - to) times. Python's hashlib computed them,
# independently of monocypher:
#   step = lambda k: hashlib.blake2b(b'kome/prev', key=k, digest_size=32).digest()
# Format: chain <key at From, 32-byte hex> <From> <To> <key at To, hex>
#
# Box and link known answers (DESIGN.md §6 "Boxes (D5, D6)"; AUDIT.md A6,
# G7: the ephemeral secret is derived from the epoch key and the roster's
# identity, not drawn by the caller).
# The independent Python reference below made every line on 2026-11-04:
#   Python 3 hashlib for BLAKE2b (unkeyed and keyed);
#   pyca/cryptography 50.0.1 for X25519 and ChaCha20-Poly1305, under an
#     HChaCha20 subkey written from draft-irtf-cfrg-xchacha-03;
#   the RFC 7748 §5 X25519 ladder and RFC 8439 ChaCha20 + Poly1305, written
#     in plain Python integers in the script itself.
# Two different implementations compute each primitive, and the script
# asserts that the two results agree. No monocypher code is used. (The
# first link line has the same inputs as the previous file's, which a
# libsodium-backed script made; the output is identical, so the in-script
# references also agree with libsodium.) Labels are ASCII with no
# terminator, u16 and u48 are big-endian:
#   eph_sk   = BLAKE2b-256("kome/eph" || k_e || ns[16] || u16(e) || signer
#                          || u48(gen))                            (96 bytes)
#   box_pk   = X25519_Public(eph_sk)
#   wrap_key = BLAKE2b-256("kome/wrap" || X25519(eph_sk, dh_pk) || box_pk
#                          || dh_pk || sign_pk || ns[16] || u16(e))   (155 bytes)
#   nonce    = BLAKE2b-256("kome/nonce" || wrap_key || k_e)[0:24]
#   box      = XChaCha20-Poly1305(wrap_key, nonce, AD = ns || u16(e), k_e)
#   link_key = BLAKE2b-256("kome/link" || k_s || ns || u16(s))
#   nonce    = BLAKE2b-256("kome/nonce" || link_key || k_{s-1})[0:24]
#   link box = XChaCha20-Poly1305(link_key, nonce, AD = ns || u16(s), k_{s-1})
# The first four box lines are the reviewer's k5/k6 case: the same member
# and signer at epochs 5 and 6 under one gen (the epoch key alone changes
# eph_sk), then epoch 6 under the next gen, then under another signer.
# The derivation inputs of each box are its first five fields (k_e, ns, e,
# signer, gen); eph_sk and box_pk are what Kome.Epochs.Eph_Secret_Of and
# Box_PK_Of must give for them. No box or link key here is all zeros
# (Box_Key and Seal_Link refuse an all-zero key, A27); the all-zero chain
# key is only a Derive input.
# Format:
#   box  <k_e> <ns> <e> <signer> <gen> <member_dh_sk> <member_sign_pk>
#        <eph_sk> <box_pk> <member_dh_pk> <wrap_key> <nonce> <box>
#   link <k_s> <ns> <s> <k_prev> <link_key> <nonce> <box>
# Reference script (gen_epochs.py, SHA-256
# 0f8161bfc7419595e62a462090e9ca3e26d3cb5ca2405ebdc68467027069c00c). Extract and run it
